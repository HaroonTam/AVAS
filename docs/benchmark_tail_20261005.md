# 已有多轮实验的尾部延迟诊断

2026-10-05，对 [三轮实验](benchmark_repeated_20261005.md) 的 360 个正式样本进行离线诊断。
本次没有重新运行模型或采集新数据；已有统计与旧汇总逐字段核对一致。

## 方法

- 按总耗时降序选择全局前 10 个正式样本；并列时按轮、图片、正式采样索引升序。
- 对每个样本，以同轮、同图片的 30 个正式样本（包含被选样本）各阶段中位数作参照。
- 阶段增量为原始耗时减去参照中位数，可为负；不同阶段中位数不一定来自同一个样本，
  因此阶段中位数及增量不能当作可相加的总耗时分解。
- JSON 的 run_index/image_index/sample_index 从 0 开始，分别定位 sources、images 和正式 samples；
  下表将轮次和正式采样序号转换为从 1 开始，便于阅读，不包含预热。
- 全局前 10 并不代表每张图片的尾部，也不是自动异常阈值；不同图片尺寸和常态耗时影响入选。

现有 depth 墙钟包含预处理、推理、结果回传、原图尺寸恢复和校验；检测也包含多个处理环节。
若继续，应在独立、可关闭的诊断模式中明确 GPU 同步计时边界和测量扰动，并保留当前主机墙钟基线；
不能直接比较有额外同步的诊断计时与当前基准，也不应在定位前修改模型或精度设置。
