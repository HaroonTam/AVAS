# Windows 本地受限语音输入

本阶段提供按次触发的命令 STT，不是自由听写、唤醒词或持续监听。
通过 System.Speech 的已安装 `zh-CN` 识别器和固定语法，在隐藏 PowerShell 子进程中完成识别。
接口依据：[Microsoft SpeechRecognitionEngine 文档](https://learn.microsoft.com/en-us/dotnet/api/system.speech.recognition.speechrecognitionengine?view=netframework-4.8.1)。
没有新增 Python 依赖、模型下载、云服务或录音文件。

## 显式运行

```powershell
D:\python\python.exe -m app.live --console --voice-input --no-speech
```

该命令会启动真实摄像头，但构造识别器不会打开麦克风。
在控制台输入 `听取` 或 `listen` 并回车后，才启动一次麦克风识别。
支持以下完整短语：

- 描述周围
- 当前风险
- 寻找椅子
- 寻找人
- 寻找自行车
- 寻找汽车
- 寻找公交车
- 寻找摩托车

识别结果只映射到已有的只读查询命令，不支持语音修改规则、退出程序或控制告警。
识别多个同类目标时仍按现有方式要求消歧；帧 ID 和目标 ID 的选择目前使用键盘。
语音输入名称不代表当前帧存在该目标，也不改变检测模型的实际类别支持范围。

需要本地回答朗读时运行：

```powershell
D:\python\python.exe -m app.live --console --voice-input --speak-replies
```

该组合开启摄像头，并可播放告警与普通回答；麦克风仍须每次输入 `听取` 启动。
识别完成、超时或取消后关闭子进程并释放麦克风，然后才处理回答。
紧急告警不会因正在听取而暂停；麦克风可能拾取扬声器声或其他人说话，
目前没有回声消除、说话人验证或唤醒词。真实测试应检查这类误触发及耳机使用效果。

## 配置与故障

`configs/system.ini` 的 `[stt]`：

- `timeout_s=10`：从创建子进程前开始计时的总等待上限，允许 1–30 秒。
- `min_confidence=0.7`：固定语法识别分数阈值，允许 0–1，未经实地验证，不是安全概率。

每次识别有独立进程，启动耗时占用总等待时间，尚未测量。提示出现不代表音频设备已经就绪。
`.NET Recognize(TimeSpan)` 参数只限制初始静音，因此 Python 另行使用总截止时间与强制进程回收，
避免语音持续输入使识别一直等待。回收最多另等 1 秒；操作系统进程启动本身不提供硬实时保证。
关闭控制台会传递取消信号，停止听取并丢弃迟到结果；正常输入 `quit` 在听取完成后处理。
Ctrl+C 的主循环退出仍受现有原生模型推理无硬超时这一限制。

识别状态：`recognized`、`unrecognized`、`timeout`、`cancelled`、`unavailable`。
只有已知短语且分数达标时才会调用 Agent；未知、低分数或畸形结果不执行查询。
缺少识别器、麦克风不可用或后端错误会显示不可用提示，之后仍可键盘查询和退出。
单次 STT 失败以命令状态报告，不自动终止实时运行；即时风险告警保持独立。
目前 STT 错误反馈是控制台文字，尚未增加专用的无障碍错误语音。

需要 Windows PowerShell、System.Speech、已安装的 `zh-CN` 识别器和默认录音设备。
中文 TTS 声音与中文 STT 识别器是不同组件，存在中文朗读声音不保证能识别。
本机只读枚举发现 `MS-2052-80-DESK / zh-CN`（另有 zh-TW），
生成脚本通过了 PowerShell 语法解析。沙箱内初始化报 SAPI 引擎不可用，
沙箱外初始化及固定语法加载通过；后者显式移除了默认音频设备绑定和 Recognize 调用。
这验证了本机后端构造能力，不验证麦克风、录音、识别效果或播放。

## 数据与验证边界

程序不保存或上传原始音频；子进程只返回固定词表内的文字及分数，
不把自由转写内容或底层异常正文写入日志。控制台会显示已接受的规范化命令。
这是当前项目代码的数据行为，不是对整个操作系统其他应用的隐私保证。

14 项新增合成测试覆盖参数、全部命令、分数边界、畸形结果、隐藏进程参数、
构造不录音、超时强制回收、取消后丢弃、轮询恢复、故障保留键盘、入口接线，
以及听取期间告警独立提交。测试全部使用模拟子进程与输入。
尚未测量中文识别准确率、噪声条件、误触发率、麦克风兼容性、启动延迟或真实可用性。
