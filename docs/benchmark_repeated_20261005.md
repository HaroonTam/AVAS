# 三轮离线多图片实验：2026-10-05

在修改应用代码之前，以固定修订连续启动三个新的 Python 进程，每轮使用相同四张图片。
只测离线处理延迟，不推断精度、米制误差或真实行走安全性。完整命令见 [基准说明](benchmark.md)。

- 测量代码修订：`97499e4e5e975beb3c6781a4e9f5cb4e7befd0d9`；三份报告均为 `code_dirty=false`。

- 三份报告中的原应用源码哈希均与文件核对一致，之后新增的汇总模块不属于采样源码。
