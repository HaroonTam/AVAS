# E2 平面板预采集操作

工具：`python -m app.e2_capture`。仅采集本地原图与人工板面 ROI，不运行 YOLO 或深度模型，
不生成 MetricEvidence。预采集全部标记 development_precapture，不进入独立测试集。
相机由用户执行以下命令后打开；无音频、网络、模型下载，正常 app.live 行为不变。

## 准备与测量

1. 关闭占用相机的软件。固定电脑与屏幕，保持用户确认的屏幕竖直、镜头水平朝前、
   镜头中心离地约 26.5 cm；安装改变就使用新的 installation-id，不混用标定。
2. 准备约 60×60 cm 或更大的哑光板，竖直正对镜头，在离地 26.5 cm 处作中心标记。
   光轴附近板面应平整，避免反光、遮挡；普通板不保证 YOLO 能检测。
3. 从镜头外壳参考平面的地面投影量到板前表面的地面投影，不从笔记本前沿起量。
   记录实际读数（米），不要把目标档位当测量值。外壳到光学中心偏移未知，记录不会假设其为零。
4. 建议 0.5、1、1.5、2、3 m 各 4 次独立重新摆放。距离是预采集网格，不是有效范围。
   同一布景保留同一 group-id；只挪动板不构成新的独立布景。不同背景/光照改变才另记布景。

## 用户执行：先采一条

```powershell
Set-Location 'D:\A Visual Assistance System for Visually Impaired People Based on YOLO11 and Depth Anything V2'
$e2Distance = Read-Host '实际测量距离（米，例如 0.503）'
$e2Instrument = Read-Host '测量工具与标称精度（未知请写未知）'
$e2Conditions = Read-Host '室内或室外、光照、背景及异常情况'
D:\python\python.exe -m app.e2_capture --save-local --distance-m $e2Distance --group-id scene01 --installation-id omen_h0265_v1 --instrument $e2Instrument --conditions $e2Conditions
$LASTEXITCODE
```

明确知道总测量不确定度时可加 `--uncertainty-m 0.01`（仅为参数示例，不是默认精度）；
未提供时 JSON 保留 null。仪器标称精度不等于包括参考点与摆放误差的总不确定度。

程序请求 index 0、640×480、启动预算 15 秒、后续读取预算 3 秒，丢弃首包并拒绝陈旧帧。
它会先释放相机，再展示冻结图像：鼠标框选板面，Enter 确认；C 取消。
检查框内确为板面、画面清晰、读数对应当前摆放、安装没变后，在终端输入 `yes` 才保存。
选框取消、输入其他文字或 Ctrl+C 都不会形成有效样本；失败返回 2，取消通常返回 1，成功返回 0。
空框按无效输入返回 2。OpenCV 窗口后端不可用时保留报错，不宣称采集成功。

成功后打印 `outputs/e2_<唯一标识>/record.json`；同目录 `frame.png` 是未经绘框/缩放的原图。
每次运行创建新目录，不覆盖。PNG 保存失败或记录写入失败的残留目录不算有效样本；保留排查，不自动删除。
重复采样只需重新摆放、重新测量并重跑命令。先完成一条并核对记录，再继续其余预采集。

请贴回退出码、record.json 内容或其本地路径与异常文字；不必上传原图。
实际尺寸、镜像和光轴几何仍需人工核验，记录默认 mirroring_verified=false。
可在板旁放置文字检查镜像，但不要让它遮住板面；后续正式协议冻结前记录核验结论。

## 记录与后续

记录含图像 SHA256、帧身份/采集时刻、实际尺寸、人工 ROI（原图 xyxy 半开区间）、真值、
不确定度、布景与安装标识、生产融合配置/配置哈希、代码修订、工作区状态、OpenCV 版本。
融合配置仅作为后续同图比较的快照，本入口不计算深度统计。人工 ROI 诊断与生产检测框结果须分开。
图像仅本地保存到已忽略 outputs/；不上传、不提交、不自动删除，保留期限未指定。
独立测试划分、Metric 候选审查、双模型推理与生产接入属于后续步骤。

无硬件单元测试只验证输入边界、清理、近期帧与存储规则，不代表真实相机、窗口、测距精度已验收。
