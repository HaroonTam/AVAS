# 本地文字交互

`app.agent.vision_agent.VisionAssistant` 实现受限的确定性交互流程：
文字请求 → 结构化意图 → 当前场景工具 → 输出前再次查询 → 模板回答。
无需 LLM、网络或新依赖，不访问相机、麦克风和 TTS。
提供可嵌入 Python 的文字接口，以及显式启用的 Windows 实时文字控制台。
尚无图形界面；普通回答 TTS 需要显式启用。

## 实时文字控制台

在 Windows 交互终端、项目根目录显式运行：

```powershell
D:\python\python.exe -m app.live --console --no-speech
```

该命令会打开真实摄像头并运行本地模型；`--no-speech` 禁用声音。
需要原有紧急告警语音时去掉 `--no-speech`，普通查询回答仍只显示文字。
本阶段开发验证没有执行此硬件命令。

显式启用普通回答朗读（也会开启真实摄像头与本地声音）：

```powershell
D:\python\python.exe -m app.live --console --speak-replies
```

`--speak-replies` 必须与 `--console` 同用，不能与 `--no-speech` 同用。
普通回答使用同一个语音工作线程和最低优先级 0，紧急告警继续使用原有高优先级。
显示的 `reply_speech` 状态包含入队待复核、场景失效、超长、队列拒绝、后端不可用等结果。
`queued_recheck_before_start` 只代表进入队列，不代表已播放或最终一定会播放。
已知的查询失败和不支持请求可朗读固定操作反馈，状态为 `feedback_queued`；
这也仅代表入队。超过 300 字符的事实回答仍只保留文字，不截断风险提示来凑长度。

控制台启动后输入下表中的命令，回车提交。`quit`、`exit`、`退出` 或 Ctrl+C 停止程序。
Ctrl+Z 只结束文字输入，感知与告警继续。退出信号在主循环下一次检查时生效；
原生模型推理仍没有硬超时，不能保证推理挂起时立即退出。
输入超出 256 字符会整体拒绝，需回车后重新输入；没有无界请求队列。
启用语音输入后，听取期间支持键盘 `cancel`／`取消` 取消本次识别，
以及 `quit`／`exit`／`退出` 请求结束程序；其他完整行提示未执行并丢弃。
识别取消有界等待回收，迟到结果不会变成查询，详见 [语音输入说明](voice_input.md)。
支持普通字符、回车、退格，不提供历史命令或光标编辑。

`--console` 模式隐藏逐帧 JSON；回答写入 stderr，风险和故障日志仍然保留。
日志可能与正在输入的文字交错。未启用控制台时保持原有逐帧 JSON 行为。
重定向 stdin、非 Windows 平台及不提供真实终端的 IDE 窗口不受支持，
会在加载模型和启动设备前明确失败。建议使用 Windows Terminal 或 PowerShell 终端。
控制台输入或查询故障不会停止后续感知和告警；记录故障后最终退出码为 2。
没有新增文件保存，用户自行重定向输出可能保存场景信息。

## 支持的请求

| 文字 | 行为 |
| --- | --- |
| `描述周围` / `周围有什么` / `describe` | 查询简短环境摘要 |
| `左侧有什么` / `前方有什么` / `右侧有什么` | 不指定类别，查询对应图像方向的简短摘要；三个短语也支持固定语音识别 |
| `当前风险` / `有什么危险` / `risks` | 返回引擎的危险和降级提示 |
| `寻找 椅子` / `find chair` | 精确查找类别；多个匹配要求选择 |
| `椅子在哪里` / `椅子有多远` | 返回匹配对象的方向与可用距离 |
| `左侧的椅子在哪里` / `前方的椅子有多远` | 仅查找指定图像方向；支持左侧、前方、右侧和已有六个中文类别 |
| `距离 帧ID 目标ID` / `distance frame_id object_id` | 显式指定帧内对象 |

方向查询每次重新读取当前帧，不依赖上次对话或跨帧 ID。方向是上游给出的图像相对方向，
不是世界坐标或行走指令；方向未知的对象不参与定向匹配。无匹配不代表该方向没有目标。
同方向仍有多个匹配时必须继续消歧；整帧风险事件不随对象筛选被移除。
米制距离缺失仍明确返回不可用。文字支持“在哪里”和“有多远”，语音固定词表仅支持前者。

定向环境摘要默认最多展开三个匹配目标，先筛选再排序和限制数量；
未展开数量只计算该方向的匹配目标。方向未知的目标不猜测归属，会单独提示。
整帧危险提示不因定向摘要被过滤，摘要也不是可通行性判断。
它仍是场景事实回答，必须经过输出前复核及语音播放前凭据检查。

固定中文别名仅包含椅子、人、自行车、汽车、公交车、摩托车；
这些只是查询名称映射，不代表当前帧一定检测到目标，也不改变实际模型类别能力。
`find` 允许包含空格的原始英文类别，如 `find traffic light`。
不支持的请求明确返回 `unsupported_request`，不猜测意图，不执行文字指令。
当前没有自由对话、多轮记忆、跨帧目标跟踪或自由听写。
`--voice-input` 可启用按次听取固定命令，详见 [语音输入说明](voice_input.md)。

## 嵌入方式

```python
from pathlib import Path

from app.agent.tools import SceneTools
from app.agent.vision_agent import VisionAssistant
from app.safety.config import load_risk_config
from app.scene_store import SceneStore

store = SceneStore(load_risk_config(Path("configs/system.ini")))
assistant = VisionAssistant(SceneTools(store))
answer = assistant.respond("椅子在哪里")
print(answer.message)
```

这个示例不会打开任何设备，没有实时发布端时返回“当前环境信息不可用”。
实时嵌入方需将同一个 store 传给 `app.live.main(..., scene_store=store)`，
并在独立交互线程调用 `respond`；不要在感知循环里等待用户输入或调用交互后端。
只运行 `app.live` 不启用输入；传入 `--console` 才会创建文字交互线程。

## 事实与时效边界

`prepare(SceneRequest(...))` 保存结构化草稿，`finalize(draft)` 在输出前重新查询。
当前结果与草稿不一致（含帧 ID、采集时间、所选事实、风险、事件与消息）时，
返回 `answer_expired`，不输出旧对象信息。不会自动把旧目标 ID 映射到新帧。
草稿不接受自由生成的回答正文，最后的文本仅由重新查询的事实和固定模板生成。
伪造草稿中的米数、风险或消息无法通过一致性检查。

`AssistantAnswer` 含 `status`、`frame_id`、`message`，表示查询完成时的回答。
它不是长期有效的播放许可。`SpokenReply` 在查询前获取当前发布版本凭据，
调用现有 `respond` 完成事实复核，再将文本与凭据以最低优先级提交。
语音工作线程启动后端前检查凭据撤销状态和双时钟有效期，检查为常数时间，
不会调用 Agent、网络或重新遍历场景执行风险计算。
换帧、同帧重新发布或失效都会撤销旧凭据；排队期间失效的普通回答被丢弃。
凭据一旦过期，时钟回拨也不能使其复活。不会直接播放无凭据的缓存场景回答。

无帧的已知失败状态（请求不支持、工具不可用、场景不可用／无效／过期／变化、
回答失效或帧不匹配）只触发代码白名单内的固定反馈，不朗读回答正文。
`SpokenReply.notify` 同样只接受白名单状态，用于识别失败反馈；未知状态不发声。
这些提示只说明“本次查询／听取”的结果，不包含目标、距离、方向或当前风险事实，
因此不需要场景凭据；场景恢复后也不会错误地断言当前设备仍故障。
它们复用配置的 `freshness_ms` 作为排队期限、最低优先级和现有有界队列，
过期丢弃、告警抢占、后端故障和队列拒绝规则均保持不变。
关闭适配器后不再提交，已经入队的提示沿用队列期限／全局取消／工作线程关闭策略。
语音失败时保留文字及 `speech_unavailable` 状态，不能保证使用同一故障音频通路播报故障。

检查发生在调用本地语音后端之前，不保证硬件实际起声时场景仍有效：
Windows 每句话启动 PowerShell 的延迟尚未测量。已启动的短句允许说完，
或被高优先级告警、播放超时及显式取消停止；不会在每次换帧时截断已启动句子。
相机失效继续使用原有全局取消通路。控制台关闭阻止之后提交回答，不取消紧急告警。
高帧率与短有效期可能导致多数普通回答在开始前被丢弃，实际可用性仍需硬件实验。
高频场景更新可能让较慢交互频繁返回过期，这是无跟踪条件下的保守行为。
此机制不验证任意 LLM 自由文本；后续 LLM 接入应只提出受校验的结构化请求，
或另行实现可验证的事实输出协议，不应绕过这里的确定性渲染。

风险查询始终保留降级提示；没有规则告警不解释为道路安全。
交互模块没有修改风险、取消告警或提交高优先级语音的接口。
工具失败只返回查询不可用。合成测试验证阻塞交互期间仍能提交独立高风险告警，
不代表测量了实际语音延迟、模型精度或真实行走安全性。
