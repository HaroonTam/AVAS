# 确定性风险引擎与告警事件

## 职责和接口

- `app/safety/scene.py`：风险输入及场景身份校验，与相对深度融合接口的离线适配。
- `app/safety/config.py`：读取 `[risk]`；阈值、类别、置信度、时效和冷却配置。
- `app/safety/risk_engine.py`：无状态 `assess_scene(scene, now_ms, config)`，返回不可变评估与事件。
- `app/safety/warnings.py`：每条输入流独享 `WarningGate`，在输出前筛选重复事件。

这些模块不调用 LLM、网络、STT 或同步语音播放。输入没有 Agent 建议或可覆盖风险的参数。
融合层旧 `risk_level=unknown` 是兼容占位，权威风险结果为 `safety.assessment`；
离线适配器忽略上游自报风险和米制数值，不通过复制字段赋予其有效性。

本阶段完成的是规则与本地事件接口，未实现摄像头循环、实际 TTS、声音抢占或可访问反馈设备。
下一阶段必须让紧急事件先进入独立本地输出通路，不能等待 Agent 请求或普通语音。
静态依赖测试只证明当前模块无 Agent／网络依赖，不代表已经测试了真实 LLM 故障、语音抢占或硬件告警。

## 输入与新鲜度

`RiskScene` 含帧 ID、采集时间、来源、有效标志和对象列表，拒绝混帧、重复对象或跟踪 ID。
`captured_at_ms` 和 `now_ms` 使用同一时钟基准的整数毫秒；当前设计为 Unix 时间毫秒。
实时输入适配器必须在采集时记时，不能以推理结束时间刷新旧图像。
有效且 `0 <= now_ms-captured_at_ms <= freshness_ms` 的 live 场景可评估。
失效、无时间、未来时间或过期场景所有对象均为 unknown，发出不含旧对象事实的降级事件。
相机故障时调用方须传入 `valid=False`，不得复用旧场景冒充当前输入。

离线图片始终返回 `offline_not_current`、unknown 和空事件列表，即使附带时间也不能成为实时告警。
CLI 使用真实调用时间评估，但不会伪造离线图片的采集时间。
尚无实时场景存储与 Agent 工具，不能把这些接口解释为已完成当前场景问答。

## 米制支持与规则

`MetricEvidence` 是未来可信米制模型或标定适配器的接口：包含距离、支持记录 ID 与有效米制范围。
引擎只接受有限、非负、处于有效范围且支持 ID 非空的证据；其他输入降为 unknown。
结构校验无法验证标定记录的真实性，调用方必须提供经过实验验证的记录，不能让 LLM 或外部任意 JSON 构造证据。
当前相对深度适配器始终传入 `metric=None`；没有相对深度换算米数的隐式公式。

默认实验规则要求检测分数至少 0.5、方向 front、类别属于配置的 obstacle_labels：

| 条件 | 结果 |
| --- | --- |
| 有效米制距离 < 1.0 m | high |
| 1.0 m <= 有效米制距离 < 2.0 m | medium |
| 有效米制距离 >= 2.0 m | low，仅表示未命中此距离规则 |
| 证据不足、低置信度、方向未知或非前向、未覆盖类别 | unknown |

这些阈值是测试值，尚无实际行走验证。low 不代表道路安全。方向仍是图像相对方向，未推导世界方位。
没有运动估计、碰撞时间或轨迹预测，因此不声称支持这些风险证据。

可选 `independent_hazard_labels` 在足够检测分数、front 方向下产生 medium，独立于距离。
默认列表为空；仅用于明确配置并记录实验依据的类别规则，不能把它理解为某类别天然危险。
距离缺失或失效不会清除此独立事件；有效近距离可将其升级为 high，远距离也不取消独立 medium。
此配置不扩展检测模型的类别能力，不支持的类别不会凭空产生。

总体等级先取 high，再取 medium；若没有危险但含未知项，或没有任何检测，则为 unknown。
只有全部对象都被规则评为 low 时，总体才为 low；逐项原因和降级提示始终保留。

## 事件与去重

评估产生 `WarningEvent`：high、medium 危险事件优先于 unknown 降级提示。
文本由确定性模板生成；不补充未经验证的目标名、方向或米数。
距离未知和评估不完整有独立提示；可以与已确认危险共存，不将未知输出成“道路畅通”。

`WarningGate.select` 使用独立单调时钟毫秒参数（例如 `monotonic_ns() // 1_000_000`），
不能混用 Unix 时间；回退时间直接拒绝。默认冷却 3000 ms，等于边界可再次输出。
新事件、风险升级、消失后重现立即输出；降级后再次升级也立即输出。
同一危险的原因变化不构成新身份，等级升级才绕过冷却；危险与降级提示使用不同 key。

只有可信跟踪器提供的 track_id 可跨帧去重。当前无跟踪器，用 frame_id + 对象 ID 定位事件，
不同帧同编号不能被合并；这可能增加重复提醒，是明确的当前限制。
状态仅保留本次活动事件，最多 256 项；超出容量的事件仍输出，未缓存项可能重复，不能丢告警。
应在每次新评估后调用，不能将旧 assessment 反复当作新场景；该层不替代新鲜度检查。
事件被选中只表示提交给后续输出通路，不表示语音已经成功播放；后续输出层需实现失败反馈和重试策略。

## 验证

使用 `D:\python\python.exe -m unittest discover -s tests -v` 运行完整测试。
合成测试覆盖米制阈值等值边界、无效数值、范围外值、支持记录缺失、分数边界、独立危险、
混帧、失效／过期／未来时间、空检测、聚合未知、冷却边界、升级、重现、状态容量和帧内身份。
