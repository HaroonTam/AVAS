# 实时摄像头与本地语音

当前新增实时入口 `app.live`。它不会修改离线 `app.main` 的使用方式。
模型初始化一次，摄像头在独立进程读取，容量为 1 的进程队列在拥塞时丢弃旧帧。
每帧包含会话 UUID、递增序号、读取开始时的 Unix 毫秒及单调时钟秒数。
时间是软件读取近似，不是相机硬件曝光时间；驱动缓存仍可能增加未测量延迟。

## 运行

在项目根目录使用已有完整环境，启动即会打开相机并尝试本地中文语音：

```powershell
D:\python\python.exe -m app.live --max-frames 100
```

不设置 `--max-frames` 时持续运行，Ctrl+C 退出。静音诊断：

```powershell
D:\python\python.exe -m app.live --no-speech --max-frames 10
```

Windows 交互终端可添加 `--console`，在独立线程输入“描述周围”“寻找 椅子”等命令。
该模式隐藏逐帧 JSON，默认回答仅显示文字；`quit` 请求退出，输入故障不停止感知和告警。
同时传入 `--speak-replies` 可启用低优先级回答朗读，不能与 `--no-speech` 同用。
排队回答在语音后端启动前检查场景版本及有效期，换帧后丢弃；告警通路不等待 Agent。
语法、终端要求与退出限制见 [本地文字交互](local_assistant.md)。

`[camera]` 设置索引、请求分辨率和等待超时；设备可能不接受请求分辨率，以实际帧尺寸为准。
`[speech]` 设置 Windows 语速和单句超时。默认语音后端要求 Windows PowerShell、System.Speech
及已安装可用的中文声音。语音失败明确记录 `spoken alerts unavailable`，终端保留风险事件。
非 Windows 当前仅支持 `--no-speech` 诊断；没有提供其他平台的语音后端。
相机安装朝向不确定时必须在 `[fusion]` 设 `camera_orientation=unknown`，不要沿用前向样例假设。

不写入或上传原始图像、声音；逐帧 JSON 输出到终端，用户显式重定向才会持久化。
真实运行会包含目标观测，重定向文件需自行管理与删除。

## 失效与语音优先级

推理前拒绝过期帧，推理后再次评估时效。过期输出包含 `current_scene=false`、`scene.valid=false`，对象与观测列表清空。深度失败保留检测并继续返回未知米制距离。
相机进程故障、读取超时或检测异常使当前场景失效，取消旧语音，输出降级事件并退出。
停止感知后最多等待 5 秒让故障提示播放完，未完成时明确记录，再关闭输出资源。
运行中深度失败或语音故障最终返回退出码 2；主动静音诊断不自动算故障。
采集关闭先等待正常释放，驱动卡住时终止隔离进程，避免永久卡在读取。
模型原生推理仍运行于主线程；其内部挂起目前没有进程级超时，不能声称完成硬实时保障。

独立语音线程只接收短文本，队列默认容量 4；普通信息优先级 0，一般告警 1，高风险 2。
高优先级消息可终止正在播放的低优先级消息；排队过期消息丢弃。
已开始的短句允许说完，或因更高优先级、播放超时、关闭而停止，避免每帧时效窗口截断整句。
当前每句话启动一个隐藏 PowerShell 进程，存在启动成本，尚未实测可听告警延迟。
文本通过 Base64 编码作为数据传递，不作为 PowerShell 指令执行。
Windows 语音 API 依据：[SpeechSynthesizer 官方说明](https://learn.microsoft.com/en-us/dotnet/api/system.speech.synthesis.speechsynthesizer?view=netframework-4.6)。

`latencies_ms` 分别记录检测、深度、融合、风险和采集到提交事件的延迟；
提交事件不是实际声音开始时间，`worker_running` 也不表示扬声器已经成功发声。
`speech_accepted` 仅为本轮进入语音队列的数量。日志是现有故障反馈，尚未配置额外的可访问硬件反馈。

当前无米制支持，默认距离规则不产生 high／medium；持续未知状态可产生降级语音。
不能用此模式声称已实现可靠的行走避障。LLM 交互 Agent 和米制标定仍未实现。
受限本地 STT 已通过 `--console --voice-input` 接入，逐次输入 `听取` 才开启麦克风；
真实识别尚未验证，见 [语音输入说明](voice_input.md)。
已新增内存单帧存储与只读场景工具：告警提交后发布，相机故障与退出清空；
嵌入式使用方式和时效边界见 [Agent 工具说明](agent_tools.md)。

## 验证状态

82 项合成单元测试通过，包括基础感知、风险、队列替换、采集故障、幂等关闭、
语音抢占／取消／超时／启动失败、过期帧、实时成功输出、深度降级及场景工具。
测试不打开真实摄像头、不播放声音。Ruff lint/format、两个 CLI 帮助和离线锁检查均通过。
实际硬件、音量、中文发音、语音抢占听感、FPS、内存和真实危险准确率均未测量。

当前模型原生推理没有硬超时，终端输出也可能受接收端阻塞影响。未提供硬实时延迟保证。
Windows 每句进程启动需要现场测量；尚未完成连续帧实测 FPS、峰值内存或语音起播延迟基准。
